# slides-builder

## Build Reveal.js presentations from Markdown files

Drop numbered `.md` files into `slides/` → push → GitHub Pages deploys automatically.

Note:
Title slide using the hero theme — class: hero in YAML front matter.
Content is centred and h1 scales up to 3em. h2 loses its underline and becomes a lighter subtitle.
Press S for speaker notes. Arrow keys to navigate.
